# Contributing / المساهمة

Thanks for improving README Forge. Keep pull requests focused and explain user-visible behavior changes.

1. Use Python 3.10+ and create a virtual environment.
2. Install with `python -m pip install -e . pytest`.
3. Run `python -m pytest -q` and `python -m compileall -q src tests`.
4. Add tests for new metadata formats or rendering behavior.
5. Never add real credentials or private project data to fixtures.

شكرًا لمساهمتك. اجعل التغييرات محددة، وشغّل الاختبارات، وأضف اختبارًا لأي سلوك جديد، ولا تستخدم بيانات اعتماد أو معلومات خاصة حقيقية في أمثلة الاختبار.
